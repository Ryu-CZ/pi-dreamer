02 / correction is not more summarization

A mistaken note must lose authority.

Valid correction

Inspect source → identify conflict → explain change → commit against the expected version.

Not verification

04 / sharing is explicit; deletion is real

Project memory is not a session rewind.

Branch → project

Only current-branch entries may be captured. Once deliberately captured and written, knowledge is shared across this project’s sessions with source identity preserved.

Forking Pi does not roll back published notes. Sibling-branch capture is rejected.

Project A ≠ project B

Each project uses its own local database. No global personal memory or automatic Fabric/Hermes import.

Keep the database out of Git. Capture only evidence suitable for project sharing.

Delete a source

An explicit destructive operation.

→

Delete dependent notes

Inspect dependencies across every revision, not only the current one.

→

No resurrection

Remove affected history too. Pi’s original session and external backups are separate.
