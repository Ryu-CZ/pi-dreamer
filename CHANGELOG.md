## [0.1.0] - 2026-11-19

### Added

- Install the Pi extension from npm with `pi install npm:pi-dreamer`.
- MIT license.
- Capture current-branch text into project-local sources and create source-linked notes with versioned corrections and dependent-note deletion.
- Run manual `/dream` consolidation that searches original evidence, including uncited contradictions, before revising notes.
- Compare five memory strategies on three held-out artifact tasks with opt-in live runs and separate dream/solve cost and timing reports.
- Run offline deployment fixtures and artifact/provenance graders with `node benchmark/deployment-offline.js --out <fresh-directory>`; no model calls are made.
- Run an opt-in frozen-memory experiment comparing retrieval prompts without rerunning consolidation.
- Read prototype setup, privacy boundaries, architecture, research, and benchmark findings in the documentation.

### Fixed

- Reject extra, duplicate, ambiguous, and malformed rows in impact-table benchmark results.
